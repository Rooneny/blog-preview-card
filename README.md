# Blog Preview Card

## Overview

This is my solution to the Blog Preview Card challenge on Frontend Mentor.

I built this project to improve my HTML and CSS skills and practice creating responsive web components.

## My Project

The project is a blog preview card that includes:

- A blog illustration
- A learning category label
- A publication date
- A blog title and description
- An author profile with an image and name

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Google Fonts (Figtree)

## What I Learned

During this project, I practiced:

- Creating a structured HTML layout.
- Using CSS Flexbox to align elements.
- Adding borders, rounded corners, and box shadows.
- Styling text with the Figtree font.
- Using padding and margins to control spacing.
- Making the layout responsive for mobile and desktop screens.

## Challenges I Faced

One of my challenges was matching the text layout and spacing to the original design.

I also practiced creating a solid black shadow and adjusting the card layout for different screen sizes.

## What I Would Improve

In future projects, I want to:

- Write cleaner and more organized CSS.
- Improve my responsive design skills.
- Match the original design more accurately.
- Improve accessibility and code quality.
